# Week 2 – Selection of High-Level Case Studies

## Selected Case Studies

From the five cybersecurity case studies identified in Week 1, two
high-level case studies have been selected for detailed system design
and architecture.

### 1. Cyber Attack Path Prediction & Prevention Platform

#### Overview

Cyber Attack Path Prediction & Prevention Platform is a cybersecurity
system designed to identify possible attack paths within an organization's
IT infrastructure.

When an attacker gains access to one system, they may try to move to
other devices, servers, applications, or databases. This system analyzes
the relationships between users, devices, services, vulnerabilities, and
permissions to identify possible attack paths.

The system provides security teams with information about high-risk
paths and recommends preventive actions such as patching vulnerabilities,
restricting permissions, and improving network segmentation.

#### Why I Selected This Case Study

- It addresses a real-world cybersecurity problem.
- It involves complex system design and multiple interconnected components.
- It requires continuous monitoring and analysis.
- It can handle large-scale enterprise infrastructure.
- It is suitable for cloud-based deployment.
- It provides opportunities to design scalable and distributed services.
- It combines network security, vulnerability management, and access control.
- It has strong potential for future expansion.

#### Main Goal

The main goal is to identify dangerous attack paths before attackers
can exploit them and help security teams take preventive actions.

---

### 2. Self-Healing Security Infrastructure for Compromised Services

#### Overview

Self-Healing Security Infrastructure is a cybersecurity system designed
to automatically detect and respond when a server, application, or service
is compromised.

When suspicious activity is detected, the system analyzes the affected
service and can automatically isolate it from the network. The service
can then be restored or replaced with a clean version while security
policies are updated to prevent similar attacks.

This reduces the need for manual intervention and helps organizations
recover from cyberattacks quickly.

#### Why I Selected This Case Study

- It addresses the problem of slow response to cyberattacks.
- It combines security monitoring with automated recovery.
- It is a high-level distributed system problem.
- It is highly suitable for cloud infrastructure.
- It can use scalable and fault-tolerant architecture.
- It reduces system downtime during security incidents.
- It provides opportunities for automation and orchestration.
- It can be extended to large enterprise environments.

#### Main Goal

The main goal is to detect compromised services, contain the attack,
automatically recover the affected components, and maintain service
availability.

---

## Final Selection

The two selected high-level case studies are:

1. Cyber Attack Path Prediction & Prevention Platform
2. Self-Healing Security Infrastructure for Compromised Services

Both case studies will be studied further through detailed system design,
architecture, component identification, data flow, scalability,
security mechanisms, and cloud deployment in the upcoming stages.
