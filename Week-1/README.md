# Week 1 – Cybersecurity System Design & Architecture

## Case Studies

### 1. Cyber Attack Path Prediction & Prevention Platform

This system identifies possible paths an attacker could take after gaining
initial access to a network. It analyzes vulnerabilities, user permissions,
devices, and connections to identify risky attack paths and recommend
preventive actions.

### 2. Self-Healing Security Infrastructure for Compromised Services

This system detects when a server or application is compromised and
automatically responds by isolating the affected service, restoring it,
and applying security controls to reduce downtime and prevent further
damage.

### 3. Digital Forensic Timeline Reconstruction System

This system collects digital evidence such as system logs, authentication
records, file activities, and network events and organizes them into a
timeline. Investigators can use the timeline to understand how a cyberattack
occurred.

### 4. Insider Activity Detection Using Access Sequences

This system detects unusual behavior from authorized users by analyzing
sequences of activities such as logins, file access, downloads, database
queries, and privilege changes. It helps identify compromised accounts
and potential insider threats.

### 5. Secure Emergency Communication System Under Cyberattack

This system provides a secure communication mechanism during a cyberattack
or network failure. It protects critical messages using authentication and
secure communication methods while providing alternative communication
channels when normal infrastructure is unavailable.
